# Serenity Med Spa

A luxurious one-page website for Serenity Med Spa.

## Features
- Elegant design with custom color palette (Soft White, Champagne Gold, Warm Taupe, Pearl Beige, Deep Espresso)
- Playfair Display + Inter typography
- Full responsive layout
- GSAP scroll animations
- Before & After lightbox gallery
- Contact form with success state
- Sticky Book Now button
- Google Maps embed

## Tech
- Single HTML file
- Tailwind CSS (CDN)
- GSAP (CDN)

## Deployment
This project is ready to be imported into Bolt.new from this GitHub repository.
